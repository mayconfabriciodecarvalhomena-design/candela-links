# assets/audio/sfx/

Único efecto de sonido del proyecto: el maullido del gato, con 3
variantes entre las que se elige una al azar en cada maullido.

Coloca aquí los archivos con los nombres esperados por defecto (ver
`SFX_CONFIG.cat.sounds` en `src/config/sfx.config.js`):

- `cat-meow-1.mp3`
- `cat-meow-2.mp3`
- `cat-meow-3.mp3`

Puedes añadir, quitar o renombrar variantes editando el array `sounds`
en `src/config/sfx.config.js` — no hace falta tocar ningún otro archivo
del proyecto.
